# SiddhuMart — Next-Level E-Commerce Demo

A responsive student portfolio project built with HTML, CSS and vanilla JavaScript.

## Features
- Product search, category selection and sorting
- Shopping cart with local browser storage
- Dark/light theme preference
- Wishlist and product comparison (up to 4 products)
- Price range and discount filters
- Responsive layout and accessible labels

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Demo limitations
This is a frontend portfolio demo. Checkout does not collect payment. Real accounts, payment processing, inventory shared across users, and persistent orders require a secure backend.
